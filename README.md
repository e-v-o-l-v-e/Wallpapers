# My Wallpapers !

fish command to generate readme

```fish
for f in **.{png,jpg,jpeg}
    echo "## $f" | string replace -ar "[-_]" " " | string replace -r "\.(png)|(jpg)|(jpeg)" "" >> README.md
    echo "![](./$f)" >> README.md
    echo "" >> README.md
end

```
